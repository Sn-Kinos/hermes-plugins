# korean-ui 미번역 전수조사 — 2026-09-22

대상 빌드: `~/.hermes/hermes-agent` (0.21.x), 플러그인: `korean-ui` @ ba10015

## 조사 방법

1. **정적 수집** — hermes-agent 소스에서 채팅에 도달할 수 있는 모듈(`agent/`,
   `gateway/`, `cron/`, `tools/`, `plugins/platforms/discord/`)의 문자열 리터럴을
   AST로 추출. 이모지/대괄호로 시작하고 영어 단어가 2개 이상인 것만 후보로 남김.
   logger 호출 인자와 docstring은 제외. → 후보 606건
2. **커버리지 판정** — 각 후보를 `strings.py`의 `SEND_REWRITES` / `BG_ACTION_REWRITES` /
   `LABEL_KO`에 실제로 통과시켜(f-string 자리는 표본값으로 치환) 매칭 여부 확인.
3. **전달 경로 분류** — 각 리터럴이 넘겨지는 호출을 추적해 CLI/로그 전용(`_safe_print`,
   `logger`)과 채팅 도달(`status_callback` 계열, 어댑터 send, 턴 응답)로 분리.
4. **런타임 대조** — 봇이 과거에 discord 툴로 되읽어온 실제 Discord 메시지 191건을
   복원해 같은 판정을 적용. 플러그인 설치 시각(2026-09-20 20:30Z) 전후로 분리.

## 결론

- 플러그인은 **정상 동작 중**. 5개 seam(툴 라벨/크론 래퍼/배경검토/Discord send/standalone)이
  매 에이전트 기동마다 모두 적용된다고 로그에 남음. 실패 경고 없음.
- 툴 라벨 24종은 업스트림 `_TOOL_VERBS` 키와 **완전 일치** (누락 0).
- 스레드에서 보이는 영어 대부분은 **설치 이전 스크롤백**이다.
- 설치 이후 실제로 관측된 미번역: **2종** (아래 A).
- 소스 기준으로 아직 번역되지 않은 채팅 도달 가능 문구: **368건** (아래 C).

## A. 근본 원인 — 어댑터 seam이 엉뚱한 클래스를 패치하고 있었음

Discord 어댑터는 `kind: platform` 디렉토리 플러그인이라 로더가 프로필마다 따로 import한다
(`hermes_plugins.discord_platform`, `…__home_<digest>`). 플러그인은 `plugins.platforms
.discord.adapter`를 인트리 경로로 재import해 **아무도 인스턴스화하지 않는 사본**을 패치했고,
각 seam이 try/except로 감싸여 있어 "적용됨"이라고 로그까지 남겼다. 결과적으로
`SEND_REWRITES` / `LABEL_KO` 레이어 전체가 한 번도 발화하지 않았다.

이 때문에 아래 A절의 "관측된 미번역 2종"은 실제보다 과소 집계다 — 복원 가능했던 Discord
원문에 해당 구간이 없었을 뿐이다. 수정 후에는 로드된 모든 어댑터 클래스를 패치하고
레지스트리 `register()`를 후킹한다.

## B. 크론 래퍼 — 설정 요구를 없앰 (2026-09-22 수정)

`Cronjob Response: ...` / `To stop or manage this job...`는 스레드에 25회 남아 있지만
**전부 2026-09-20 17:00Z 이전**이다. 그 이후 세 프로필 모두 `cron.wrap_response: false`로
바뀌면서 업스트림 래퍼가 꺼졌다.

기존 플러그인은 한국어 래퍼를 쓰려면 `cron.wrap_response: false` + `cron.wrap_response_ko: true`
두 개를 요구했다. 업스트림 키를 "영어 래퍼 끄기" 용도로 전용한 셈이라 의미가 어긋났고,
설치만으로는 한국어가 되지 않았다.

수정 후: **설정 불필요.** 한국어 래퍼를 먼저 씌우고, 업스트림이 래핑 여부를 판단할 때 읽는
`_sched.load_config()`(해당 모듈이 몽키패치 seam으로 문서화한 late-bound 조회)만 그 호출
동안 `wrap_response: false`로 보이게 해 영어 래퍼를 대체한다. ContextVar로 감싸 동시 배달
간 간섭이 없다.

- `cron.wrap_response` — 업스트림 의미 유지 (래퍼 on/off, 기본 true)
- `cron.wrap_response_ko: false` — 래퍼는 유지하되 영어로 되돌리는 탈출구

세 프로필 모두 `wrap_response: false`가 남아 있으므로, 한국어 헤더를 다시 보려면 그 줄을
지우면 된다.
